# Escenario de Make

Coloca aquí:

- `escenario.blueprint.json` — el blueprint exportado desde Make
  (menú "..." del escenario → Export Blueprint).
- `capturas/` — capturas del escenario montado y de una ejecución correcta.
- Una nota breve explicando qué dispara el escenario y qué decide.

No subas credenciales ni tokens de las conexiones.
